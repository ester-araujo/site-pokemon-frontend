# Site Pokémon

Projeto acadêmico desenvolvido na disciplina de Front-End.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Objetivo
Praticar conceitos básicos de desenvolvimento front-end, como estruturação de páginas, estilização e interações com JavaScript.

## Aprendizados
- Organização de arquivos do projeto
- Estrutura básica de páginas HTML
- Estilização com CSS
- Uso de JavaScript para interações simples

## Observações
Projeto desenvolvido com apoio de ferramentas de IA como parte do processo de aprendizado.
